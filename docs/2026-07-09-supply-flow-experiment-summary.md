### 핵심 발견
1. **단순 동일가중 평균은 역효과** — 신호대잡음비가 다른 채널을 무차별로 섞으면 좋은 채널이 희석됨(49% < Phase1 55%).
2. **릿지회귀로 가중치를 학습하면 크게 개선** (62~66%) — "심플 ML 앙상블"이 실제로 통했음.
3. **지평선 미스매치 가설 확인** — 장기기관(연기금/사모펀드) 신호를 3~5일 초단기로 평가한 게 원래 문제였고, 10일 지평선에서 73%(z≈3.22)로 오늘 실험 중 가장 강한 신호.
4. **8개 투자자 유형(외국인/개인/연기금/사모펀드/투신/금융투자/은행/보험) 전부 이미 스키마에 존재**, 다 채널로 활용 가능.

## ⚠️ 오늘 저녁 최대 발견: 수급 데이터 100일 제한은 라이브러리 버그였음

- `kiwoom_rest_api`의 `BaseClient.request()`가 HTTP **응답 헤더**의 `cont-yn`/`next-key`를 읽지 않고 JSON 바디만 반환 — 우리 수집기들이 한 번도 다음 페이지를 요청한 적이 없었음.
- 실제 헤더를 직접 읽어 수동 페이지네이션한 결과: **6페이지만에 2024-01-19까지 도달**, 그 이후로도 더 있음(`cont-yn: Y`).
- `collectors/supply_demand.py`에 `_fetch_investor_flow_pages()` 추가(라이브러리 우회, 헤더 직접 읽기), `--max-pages` 옵션으로 깊은 백필 지원.
- 5종목 스모크테스트로 검증 완료(2024-01-19~2026-07-09, 600행/종목).
- **현재 전종목(2,628개) 백필 진행 중** — 완료되면 수급 데이터가 ~95일 → **2년+**로 늘어나서, 오늘의 모든 통계적 유의성 판단(특히 "데이터가 짧아서 신뢰하기 어렵다"는 단서)이 훨씬 튼튼해질 것으로 예상.
