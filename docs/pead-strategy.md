# PEAD ⊕ Value — 검증된 저회전 비대칭 알파 (KR)

한국 주식에서 **9년(2016–2026) 연구 끝에 검증된 유일한 지속 알파**. 순수 가격·수급 신호는 전부 레짐 아티팩트로 실패했고, **DART 펀더멘탈**을 더해 돌파했다.

## 신호

- **PEAD** (실적발표 후 표류): 분기 순이익 **YoY 성장률**로 종목을 횡단면 랭크. 전 세계에서 가장 견고한 아노말리.
- **⊕ 가치 (E/P)**: 연간 순이익 / 시가총액. 단독으론 거래수익 ~0이나, PEAD의 **레짐 지속성을 보강**(H60 레짐 1/4→3/4).
- **lookahead-safe**: 실적은 공시가능일(분기말+45~90일) 이후에만 사용. `t+1` 진입.

## 실전 형태 (실제 구현·수익화 가능)

| 요소 | 값 | 이유 |
|---|---|---|
| 유니버스 | ADV ≥ 200억/일 (KOSPI200급) | 공매도·차입 가능, 용량 확보. 알파가 대형주에 집중 |
| 방향 | **롱온리** | ①공매도 제약·금지기 무관 ②**롱숏은 손익비 0.96(대칭)로 붕괴, 롱온리만 손익비 1.79 비대칭 보존** |
| 보유 | 60거래일 | 드리프트 만기 |
| 진입 | **스태거드 3트랜치(20일 엇갈림)** | 진입 타이밍 분산 → IR ~2배(0.5→1.0), 손익비 비대칭 유지 |
| 집중 | top 5 등가중 | 저승률·고손익비 극대화 |
| 비용 | 편도 0.18% (실측 회전율) | 분기신호라 저회전 |

## 실제 수익 (take-home)

롱온리 바스켓 보유 시 **연 ~21~24%** (top20 +23.8%/Sharpe 0.92, top40 +20.9%/0.84) — 대형주 벤치(연 +11.8%, Sharpe 0.50)의 **2배 Sharpe**, 벤치 대비 연 +9~12% 초과. 순수 롱 자본, 공매도 불요.

## 검증된 성과

**개별 베팅 (비대칭 구조):** 승률 45% · **손익비 1.5~1.8** · 팻테일(개별 최대 +358%)

**집중 포트폴리오 (top5, H60, 롱온리 대형주):**
- 손익비 **2.05** (평균이익 +14.5% / 평균손실 +7.1%)
- 기대값 +6.4%/기간 · 누적 **+376%** (8년) · 최고기간 +88% · 최악 −17% · MDD −28%
- IR 0.75

**통계 확인:** ① rank-IC Newey-t **+5.43**, 4개 레짐 전부 t>2. ② 블록 부트스트랩(B=2000, top40 스태거드): IR 중앙값 +1.19, 95%CI [+0.30, +2.20], **재표본 100%에서 IR>0** — 소수기간 운 아님.

**무결성(룩어헤드) 검증:** 신호를 5/20/40일 늦게 행동해도 IR 0.98/0.69/0.75로 완만히 유지(붕괴 안 함) → 룩어헤드 버그 없음 + 넓은 진입 윈도우(즉시 체결 불요, 느린 트레이더도 IR~0.7).

**집중도 스윗스팟:** top20(IR 1.03, t 2.76, 손익비 1.46)이 용량·견고·손익비 균형점.

**OOS:** 전반(2016-2020)·후반(2021-2026) 양쪽 양수. 단 최근 4기(2024-2026)는 음수(-14%) — PEAD 최근 레짐 최약 + 집중이 증폭.

## 집중도 선택 (손익비 vs 견고성 프론티어)

| 구성 | 손익비 | IR | 누적 | MDD | 최근2년 |
|---|---|---|---|---|---|
| top5 (최대공격) | 2.05 | 0.75 | +376% | −28% | −14% |
| top20 | 1.65 | 0.52 | +56% | −15% | +3% |
| **top40 (올라운드)** | 1.79 | 0.87 | +78% | −7% | +5% |

**손익비를 위해 견고성을 희생할 필요 없음** — top40 분산도 손익비 1.79 유지 + IR 최고 + MDD 최저 + 최근 양수. **top5는 손익비·총수익 최대이나 취약**(최근 −14%, MDD −28%, 용량 작음). 저승률·고손익비 구조는 전 집중도에서 유지(손익비 ≥1.5).

## 용량 (capacity)

선택 top5 종목 ADV 중앙값 ~422억/일. 보수적(하위25% ADV, 단일일 체결) 참여 5%→~69억, 10%→~138억; 60일 리밸런스를 3~5일 분산 체결하면 ~350~700억+. **개인/소형펀드 규모(~100억~1000억+)엔 충분, 조 단위는 아님.** 집중(top5)의 용량 한계 — top10~20 분산은 용량↑·손익비↓.

## 정직한 한계

- **섹터 분산 양호**: 선택 종목이 19개 섹터에 분산, 최대 편중 16%(전기/전자) — 단일섹터 베팅 아님. 단 단일 리밸런스 시점엔 일시 집중 가능.
- **긴 알파 가뭄**: 최장 수중기간 ~2.5~3년(초과수익이 새 고점 없이 정체) — 배포 시 강한 확신 필요. 2024가 성과 상당부분 기여, 2026(최근) 약세.
- 집중 top5 = **단일종목 위험, 큰 드로다운**(MDD −28%), 표본 작음.
- H90/120의 화려한 숫자(손익비 6+, +1111%)는 **비중첩 표본 부족(n=15~21) 착시** — 미검증.
- 8년 분기 데이터 = 장기 승자태우기 검증엔 이력 부족.
- top-400/800 현재유동성 기준 = 경미한 survivorship (point-in-time 유동성 플로어로 완화).
- **비용 내성**: 현실비용 3배(0.50%/편도)서도 IR 양수(top5 0.70, top40 0.50) — 저회전(스태거드 0.33/스텝) 덕.
- 검증에서 **기각된** 고도화: 외국인수급 결합·실적 가속도(지평선-마이닝 아티팩트).

## 실행

```bash
# 1) DART 실적 수집 (일 20,000콜 한도; 재개 가능)
export DART_API_KEY=...
uv run kq-collect-earnings --out earnings.csv --top-n 800 --from-year 2018

# 2) 백테스트 + 손익비 리포트 (실전 형태 기본값)
uv run kq-pead --db "$DSN" --earnings-csv earnings.csv \
    --horizon 60 --adv-floor 20000 --top-n 40 --value-weight 0.25 --staggered
#   --staggered: 권장 실전형태(3트랜치 엇갈림 진입, IR~1.1 t~2.9 손익비1.26)
#   --top-n 5: 최대공격(손익비2.05 누적+376%, 취약)  --market-neutral: 롱숏(손익비 붕괴, 비권장)
```
