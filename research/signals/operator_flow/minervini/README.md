## US-M01 — 글로벌맥시마 (피처선정, `feat_select.py`)

마스터 38피처(수급 8투자자 20/60d + 모멘텀 r5–r252 + RS랭크 + MA기울기 + VCP +
추세템플릿 + 거래량 + EPS yoy/accel/qoq/consec + 사이즈)에 4가지 선정법을
walk-forward OOS + 부트스트랩 CI로 비교:

| 방법 | 피처수 | OOS AUC | 95%CI |
|---|---|---|---|
| 전체 | 38 | 0.529 | [.521,.536] |
| **순열중요도** | 20 | **0.538** | [.529,.546] |
| L1 | 24 | 0.535 | |
| 전진선택 | 8 | 0.533 | |

**결론:** 어떤 부분집합도 base(0.536)를 유의하게 넘지 못함. 글로벌맥시마 ≈ AUC 0.538.
전체 38은 오히려 과적합(0.529). **AUC ~0.54가 정보 한계** — 4방법이 모두 확인.

## US-M05 — 하프켈리 포트폴리오 (`portfolio_halfkelly.py`)

"야생의 한국" 갭 리스크(1.7% 트레이드가 손절 관통, 최악 −92%). 단일베팅 켈리는
순차 가정이라 동시·상관·팻테일 현실에 과대(21.9%로 4종목 → −66% DD). **포트폴리오
레벨에서 켈리 역산**(사이즈 스윕해 CAGR 최대화):

| 포지션 | 동시 | CAGR | MaxDD | Sharpe |
|---|---|---|---|---|
| 풀 켈리 1.0% | 100 | +17.5% | −41% | 1.16 |
| **하프 켈리 0.5%** | **200** | **+12.2%** | **−24%** | **1.26** |

**최종 시스템:** 수급 스텔스매집 + 20일 돌파(거래대금 10–50억) → 5% 하드손절 →
장기보유(수익 길게) → **하프켈리 0.5%/포지션, ~200종목 초분산**. 9.3년 **2.90배,
CAGR +12.2%, MaxDD −24%, Sharpe 1.26.**

- TBA(이론 기대치) vs RBA(실현 결과)의 간극은 **포지션 사이징**이 가른다.

## 격차 좁히기 (미너비니 피드백 이식, GOAL 루프 1-9)

미너비니 대비 격차 4개를 순차 이식하며 통계 검증:

- **격차#2 레짐타이밍:** 시장지수 MA200 필터는 초분산 소형북엔 무익(과다절단). 자기
  자산곡선 디리스킹도 수익↔낙폭 맞바꿈만. **단 집중 북에선 breadth 레짐이 도움**(2018-21 출혈 완화).
- **격차#1 추세템플릿 정화:** close>MA50>MA150>MA200 + MA200 우상향 + 52주저점+25% +
  52주고점-25%내. 2R율 31.6→34.4%, ML상위10% 승률 40%. 집중 가능해짐.
- **격차#3 유니버스 질(최대 지렛대):** 거래대금 하한 10-50억 소형 → **100억↑ 주도주 체급**.
  트레이드 평균 +6.4→+11.8%, 갭 완화(기관이 유동주를 추세로 끌어올림).
- **격차#4 갭/사이징:** 하드 5% 손절이 소형주 갭에 관통(-92%) → 100억↑에서 -55~-30%로 완화.

**최종 시스템:** 수급 스텔스매집+돌파 → 추세템플릿 정화 → 100억↑ 주도주 → 5% 손절 →
장기보유 → 2% 사이징(≤50종목) → breadth 레짐(약세 차단).

| | CAGR | MaxDD | Sharpe |
|---|---|---|---|
| 출발(소형 초분산) | +12.2% | −24% | 1.26 |
| **최종(주도주 집중+레짐)** | **+32.9%** | −23% | 1.23 |
| ㄴ OOS train 2018-22 | +7.3% | −21% | 0.74 |
| ㄴ OOS test 2023-26 | +82.0% | −15% | 1.75 |

**CAGR 2.7배**(12→33%), 낙폭·Sharpe 유지. 피라미딩(+2.15R) 오버레이 여지. 미너비니 격차의
핵심은 예측이 아니라 **유니버스 질 + 집중 + 레짐**이었음 — 그의 조언 그대로.

## ★중대한 자기교정 — 스텔스는 리더 유니버스에선 엣지가 아니다 (GOAL 루프 33-34)

애블레이션을 엄밀히 재검증하다 **제 포트폴리오 시뮬의 현금-축퇴 버그**를 발견하고 교정:
2%리스크÷5%손절 = 종목당 40% 명목 → 현금이 2-3종목이면 소진 → 같은날 진입순서에 결과 좌우
(순서 민감·비재현). 이 착시가 "스텔스無 +8% vs 有 +38%"(루프32)를 만들었음.

**분산 고정(종목당 5% 상한, 20+ 동시) + 순서독립 per-trade로 재검증한 진짜 결과:**

| 검증(순서독립) | 스텔스無 | 스텔스有(top70) |
|---|---|---|
| 분산 포트폴리오 | +21.3% / Sh0.67 | +21.6% / Sh0.69 |
