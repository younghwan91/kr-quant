> **리포터 문서다 (R3).** 아래 숫자를 사람이 읽고 kill/continue 를 판단한다. 코딩된 PASS/FAIL 임계값 없음.

## 사전등록 1차 CONFIG (R1 — 결과를 보기 전에 확정)

이 **딱 하나의 config 가 THE 테스트다.** 그리드 argmax 로만 사는 값은 합격 아님.

- **top_n = 3** — 매 리밸런스 서프라이즈 확신 최상위 3개만 (pead_gate 는 40 = 분산형). Step -1: top3 = MEASURABLE BUT THIN.
- **보유상한 hold = 10거래일**, **하드손절 stop = 10%** (R 정규화 분모). 왼꼬리를 −1R 에 절단.
- **서프라이즈 floor = TRAIN top-decile YoY(q=0.90) = +3.822** — TRAIN(진입<2022-01-01)에서만 학습해 전방 적용(no-lookahead).
- **절대수익**(벤치마크 안 뺌), 리밸런스 20거래일 간격, 유니버스 ADV≥20000(pead BASELINE 동일).
- **타이밍:** 신호 t종가 → **t+1 종가 진입** → 이후 종가로 손절/보유상한 청산.

floor 가 걷어낸 (top_n 후보) 슬롯 = 4개, 실제 사용 리밸런스 115회 → 트레이드 340건, 진입 2017-03-23~2026-07-14.

**pead_refinement 정론 재해석 caveat:** PEAD 는 검증된 60일 드리프트 알파다. 여기서 10일 보유 + 손절로 **스윙화**하는 것은 원 알파의 지평을 자르는 재해석 — 드리프트 전량회수가 아니라 '프랍 모양(두꺼운 건당)' 여부만 묻는다.

## 사람이 읽는 kill/continue 메모 (코딩된 임계값 아님, R3)

_아래는 게이트 러너가 남기는 관찰 프롬프트다. 최종 판단은 team-lead/사람이 한다._
- clean-OOS 폴드 카운트가 무작위 음성대조 도달 빈도를 유의미하게 넘는가? (thin 표본 → 넘어도 CI 폭을 함께 볼 것)
- 집중형 R-분포가 분산형보다 **왼꼬리 절단·낮은 monster** 로 '프랍형'이 됐나, 아니면 monster/왜도만 커졌나(소수 괴물 의존 = 프랍에 더 나쁨)?
- 기대값 95%CI 가 0 을 넉넉히 넘는가, 폭이 너무 넓어(±수 R) 측정 불가인가?
- 미접촉창(12일·36건)이 폴드와 같은 방향인가 — 단 이 창 하나로 확정 금물.
- 사전등록 config 가 민감도 격자에서 고원인가, 홀로 튀는 spike 인가?
