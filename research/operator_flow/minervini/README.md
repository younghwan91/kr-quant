# Minervini-style ML swing — 통계적 글로벌맥시마 + 청산 + 피라미딩 + 하프켈리 포트폴리오

수급 스텔스 매집 + 돌파 신호에 미너비니 원칙(수익 길게·손실 짧게·리스크 최우선)을
이식하고, 통계적으로 검증한 전체 파이프라인. 이벤트 = 거래대금 10–50억 종목이 20일
고가를 종가 돌파. 라벨 = 4주 내 −5% 전에 +10%(2R) 달성?

## US-M01 — 글로벌맥시마 (피처선정, `feat_select.py`)

마스터 38피처(수급 8투자자 20/60d + 모멘텀 r5–r252 + RS랭크 + MA기울기 + VCP +
추세템플릿 + 거래량 + EPS yoy/accel/qoq/consec + 사이즈)에 4가지 선정법을
walk-forward OOS + 부트스트랩 CI로 비교:

| 방법 | 피처수 | OOS AUC | 95%CI |
|---|---|---|---|
| 전체 | 38 | 0.529 | [.521,.536] |
| **순열중요도** | 20 | **0.538** | [.529,.546] |
| L1 | 24 | 0.535 | |
| 전진선택 | 8 | 0.533 | |

**결론:** 어떤 부분집합도 base(0.536)를 유의하게 넘지 못함. 글로벌맥시마 ≈ AUC 0.538.
전체 38은 오히려 과적합(0.529). **AUC ~0.54가 정보 한계** — 4방법이 모두 확인.

## US-M02 — VCP (`prep_vcp.py`)

정량 VCP(연속 변동성수축 + 거래량 마름 + 타이트 베이스 + 신고가 근접)는 2R율을
개선하지 못함(VCP 29.6% vs base 30.5%). VCP 4피처 단독 AUC 0.519(거의 랜덤).
실제 VCP는 시각적 패턴이라 일봉에서 정량화 한계.

## US-M03 — 미너비니 청산 (`sim_mnv_exit.c`)

하드손절 ≤10% + 본전규칙 + 50일선 트레일 + 반절 + violations를 walk-forward
108조합. **선택: 하드 10% + 장기보유** (50MA트레일·반절·violations는 승자를 잘라
저하). +6.25%/트레이드, 5/7년. **★최악 −92%: 갭이 손절을 관통** → 단일트레이드
≤10% 보장 불가(소형주 거래정지/폭락). 반드시 사이징으로 통제.

## US-M04 — 피라미딩 (`sim_pyramid.c`)

add-and-reduce(추가매수 시 스탑 상향, 총 달러리스크 고정, 물타기 금지):

| | R-멀티플 | 손익비 |
|---|---|---|
| 단일진입 | +0.11R | 4.1 |
| **피라미딩 step8/최대4** | **+1.02R** | 19.3 |

총 달러리스크를 고정한 채 승자에 겹겹이 실어 **R-멀티플 ~10배**. 예측(AUC 천장)이
아닌 자금관리로 수익을 키우는 미너비니 핵심.

## US-M05 — 하프켈리 포트폴리오 (`portfolio_halfkelly.py`)

"야생의 한국" 갭 리스크(1.7% 트레이드가 손절 관통, 최악 −92%). 단일베팅 켈리는
순차 가정이라 동시·상관·팻테일 현실에 과대(21.9%로 4종목 → −66% DD). **포트폴리오
레벨에서 켈리 역산**(사이즈 스윕해 CAGR 최대화):

| 포지션 | 동시 | CAGR | MaxDD | Sharpe |
|---|---|---|---|---|
| 풀 켈리 1.0% | 100 | +17.5% | −41% | 1.16 |
| **하프 켈리 0.5%** | **200** | **+12.2%** | **−24%** | **1.26** |

**최종 시스템:** 수급 스텔스매집 + 20일 돌파(거래대금 10–50억) → 5% 하드손절 →
장기보유(수익 길게) → **하프켈리 0.5%/포지션, ~200종목 초분산**. 9.3년 **2.90배,
CAGR +12.2%, MaxDD −24%, Sharpe 1.26.**

## 종합 결론 (정직)

- 예측(ML)의 정보 한계는 AUC ~0.54 — 피처 엔지니어링으로 못 넘음.
- 진짜 수익은 **자금관리**에서: 피라미딩(R-멀티플 ~10배) + 하프켈리 초분산(갭 리스크
  통제, Sharpe 1.26).
- **미너비니의 집중(4–8종목)은 이 신호(승률 10% + 팻테일)엔 위험** — 초분산이 정답.
- TBA(이론 기대치) vs RBA(실현 결과)의 간극은 **포지션 사이징**이 가른다.
