# Minervini-style ML swing — 통계적 글로벌맥시마 + 청산 + 피라미딩 + 하프켈리 포트폴리오

수급 스텔스 매집 + 돌파 신호에 미너비니 원칙(수익 길게·손실 짧게·리스크 최우선)을
이식하고, 통계적으로 검증한 전체 파이프라인. 이벤트 = 거래대금 10–50억 종목이 20일
고가를 종가 돌파. 라벨 = 4주 내 −5% 전에 +10%(2R) 달성?

## US-M01 — 글로벌맥시마 (피처선정, `feat_select.py`)

마스터 38피처(수급 8투자자 20/60d + 모멘텀 r5–r252 + RS랭크 + MA기울기 + VCP +
추세템플릿 + 거래량 + EPS yoy/accel/qoq/consec + 사이즈)에 4가지 선정법을
walk-forward OOS + 부트스트랩 CI로 비교:

| 방법 | 피처수 | OOS AUC | 95%CI |
|---|---|---|---|
| 전체 | 38 | 0.529 | [.521,.536] |
| **순열중요도** | 20 | **0.538** | [.529,.546] |
| L1 | 24 | 0.535 | |
| 전진선택 | 8 | 0.533 | |

**결론:** 어떤 부분집합도 base(0.536)를 유의하게 넘지 못함. 글로벌맥시마 ≈ AUC 0.538.
전체 38은 오히려 과적합(0.529). **AUC ~0.54가 정보 한계** — 4방법이 모두 확인.

## US-M02 — VCP (`prep_vcp.py`)

정량 VCP(연속 변동성수축 + 거래량 마름 + 타이트 베이스 + 신고가 근접)는 2R율을
개선하지 못함(VCP 29.6% vs base 30.5%). VCP 4피처 단독 AUC 0.519(거의 랜덤).
실제 VCP는 시각적 패턴이라 일봉에서 정량화 한계.

## US-M03 — 미너비니 청산 (`sim_mnv_exit.c`)

하드손절 ≤10% + 본전규칙 + 50일선 트레일 + 반절 + violations를 walk-forward
108조합. **선택: 하드 10% + 장기보유** (50MA트레일·반절·violations는 승자를 잘라
저하). +6.25%/트레이드, 5/7년. **★최악 −92%: 갭이 손절을 관통** → 단일트레이드
≤10% 보장 불가(소형주 거래정지/폭락). 반드시 사이징으로 통제.

## US-M04 — 피라미딩 (`sim_pyramid.c`)

add-and-reduce(추가매수 시 스탑 상향, 총 달러리스크 고정, 물타기 금지):

| | R-멀티플 | 손익비 |
|---|---|---|
| 단일진입 | +0.11R | 4.1 |
| **피라미딩 step8/최대4** | **+1.02R** | 19.3 |

총 달러리스크를 고정한 채 승자에 겹겹이 실어 **R-멀티플 ~10배**. 예측(AUC 천장)이
아닌 자금관리로 수익을 키우는 미너비니 핵심.

## US-M05 — 하프켈리 포트폴리오 (`portfolio_halfkelly.py`)

"야생의 한국" 갭 리스크(1.7% 트레이드가 손절 관통, 최악 −92%). 단일베팅 켈리는
순차 가정이라 동시·상관·팻테일 현실에 과대(21.9%로 4종목 → −66% DD). **포트폴리오
레벨에서 켈리 역산**(사이즈 스윕해 CAGR 최대화):

| 포지션 | 동시 | CAGR | MaxDD | Sharpe |
|---|---|---|---|---|
| 풀 켈리 1.0% | 100 | +17.5% | −41% | 1.16 |
| **하프 켈리 0.5%** | **200** | **+12.2%** | **−24%** | **1.26** |

**최종 시스템:** 수급 스텔스매집 + 20일 돌파(거래대금 10–50억) → 5% 하드손절 →
장기보유(수익 길게) → **하프켈리 0.5%/포지션, ~200종목 초분산**. 9.3년 **2.90배,
CAGR +12.2%, MaxDD −24%, Sharpe 1.26.**

## 종합 결론 (정직)

- 예측(ML)의 정보 한계는 AUC ~0.54 — 피처 엔지니어링으로 못 넘음.
- 진짜 수익은 **자금관리**에서: 피라미딩(R-멀티플 ~10배) + 하프켈리 초분산(갭 리스크
  통제, Sharpe 1.26).
- **미너비니의 집중(4–8종목)은 이 신호(승률 10% + 팻테일)엔 위험** — 초분산이 정답.
- TBA(이론 기대치) vs RBA(실현 결과)의 간극은 **포지션 사이징**이 가른다.

재현: 컨테이너에서 `prep_*.py`로 이벤트/경로 덤프 → 호스트 `mlenv`에서 `feat_select.py`,
`portfolio_halfkelly.py`, `gcc -O3 sim_mnv_exit.c`/`sim_pyramid.c`.

## 격차 좁히기 (미너비니 피드백 이식, GOAL 루프 1-9)

미너비니 대비 격차 4개를 순차 이식하며 통계 검증:

- **격차#2 레짐타이밍:** 시장지수 MA200 필터는 초분산 소형북엔 무익(과다절단). 자기
  자산곡선 디리스킹도 수익↔낙폭 맞바꿈만. **단 집중 북에선 breadth 레짐이 도움**(2018-21 출혈 완화).
- **격차#1 추세템플릿 정화:** close>MA50>MA150>MA200 + MA200 우상향 + 52주저점+25% +
  52주고점-25%내. 2R율 31.6→34.4%, ML상위10% 승률 40%. 집중 가능해짐.
- **격차#3 유니버스 질(최대 지렛대):** 거래대금 하한 10-50억 소형 → **100억↑ 주도주 체급**.
  트레이드 평균 +6.4→+11.8%, 갭 완화(기관이 유동주를 추세로 끌어올림).
- **격차#4 갭/사이징:** 하드 5% 손절이 소형주 갭에 관통(-92%) → 100억↑에서 -55~-30%로 완화.

**최종 시스템:** 수급 스텔스매집+돌파 → 추세템플릿 정화 → 100억↑ 주도주 → 5% 손절 →
장기보유 → 2% 사이징(≤50종목) → breadth 레짐(약세 차단).

| | CAGR | MaxDD | Sharpe |
|---|---|---|---|
| 출발(소형 초분산) | +12.2% | −24% | 1.26 |
| **최종(주도주 집중+레짐)** | **+32.9%** | −23% | 1.23 |
| ㄴ OOS train 2018-22 | +7.3% | −21% | 0.74 |
| ㄴ OOS test 2023-26 | +82.0% | −15% | 1.75 |

**CAGR 2.7배**(12→33%), 낙폭·Sharpe 유지. 피라미딩(+2.15R) 오버레이 여지. 미너비니 격차의
핵심은 예측이 아니라 **유니버스 질 + 집중 + 레짐**이었음 — 그의 조언 그대로.

## 수렴 판정 (GOAL 루프 10-13)

- **피라미딩:** per-trade R은 +6.66R로 크나, 다유닛 포지션이 갭 맞으면 −71.5R → R-멀티플
  포트폴리오는 자본제약 무시한 착시(−75%+ DD). 단일진입(+29~36%)이 견고한 배포답.
- **ML 선택:** 정화 100억 유니버스(base 2R율 43.4%)에서 ML OOS AUC 0.482(랜덤 이하),
  상위/하위 구분 불가. **규칙이 이미 선정을 해서 ML 불필요** — 미너비니 철학 그대로.
- **시리얼 갭퍼 필터:** 주도주 유니버스엔 무익(최악 −82% 그대로).

**결론: 백테스트 최적화 수렴.** 여기서 더 파라미터를 만지면 오버피팅. 진짜 다음 단계는
백테스트 튜닝이 아니라 **FORWARD** — 실시간 스캐너 + RBA(실현결과) 축적 + 컨센서스 초대형
트랙. 미너비니의 마지막 조언(TBA 아닌 RBA로 리스크 설계)이 이 지점을 정확히 가리킨다.

## 검증·배포·용량 (GOAL 루프 16-22)

수렴 후 파라미터 튜닝(오버핏) 대신 **통계 검증 + 배포 + 견고성**을 수행:

- **블록 부트스트랩**(B=2000, 블록20일): CAGR 중앙값 +22.4%, **95%CI [+6%, +49%], 재표본
  100%가 양수**. Sharpe CI [+0.60, +2.29]. → 운이 아니라 실재하는 엣지.
- **파라미터 견고성:** 손절 4~8% 전부 CAGR +26~33%, 사이징 1~3% 전부 +26~32%. 특정값
  체리피킹 아님 = 구조적 건전.
- **시장 대비:** 유동주 등가중 Buy&Hold(CAGR +6.6%/Sh 0.39/DD −49%) 대비 **연 +22.2%p 초과,
  Sharpe 3배, 낙폭 절반.** "차라리 인덱스 사지"에 대한 답 = 아니오.
- **무익 확인(정직):** EPS 성장 필터(한국 주도주엔 기술/수급이 지배), 진입분산(이미 50종목
  시차진입), 시리얼 갭퍼 필터.
- **용량:** 100억+ 주도주(ADV 중앙 329억)로 AUM **수백억~2500억** 운용 가능(기관급).
- **배포:** `scanner_final.py`(실시간 후보+레짐) + `rba_tracker.py`(실현결과 추적) +
  airflow `daily_minervini_scan` DAG(평일 18:40, scan>>rba). 미너비니 최종조언(TBA→RBA) 실현.

**FORWARD:** 백테스트 최적화는 통계적으로 완결. 남은 건 시간(DAG로 RBA 축적, 실전=백테스트
검증)과 별개 컨센서스 초대형 트랙(상보적). 백테스트 추가튜닝은 오버핏.
